## 一、现状与目标

### 现状
- 监控对象：公开免登录招标网站（ccgp / 必联网 / 军队采购网等）

- 行业定制：高低压成套设备词库 + AI 过滤

- 数据获取：自动爬取（能登录的）+ 手动导入（不能自动的）

</column>

## 三、分阶段实施计划

### Phase 1：基础改造（1-2 周，优先级最高）

**目标**：让系统能管理已有的招标数据，先把"手动导入"这条路跑通。

| 任务 | 说明 |
|------|------|
| **1.1 平台分类重构** | `sites.py` 从"通用招标/电网/发电"改为"央企/建筑/地产/能源/钢铁/公共资源/第三方平台" |
| **1.2 手动导入功能** | 支持 Excel/CSV 导入招标信息（标题/链接/日期/平台来源/内容），解决"部分平台已有数据"的问题 |
| **1.3 数据管理看板** | GUI 和 Web 端增加"全部招标信息"总览页，可按平台/日期/关键词筛选 |
| **1.4 数据模型扩展** | `BidInfo` 增加 `platform_source`（平台来源）、`data_source_type`（auto/manual）字段 |
| **1.5 配置系统扩展** | 支持为每个平台存储账号密码（加密）、会员到期时间、爬取开关 |

**为什么先做手动导入？**
- 100+ 平台里，能全自动爬的可能只占 20-30%
- 先把"手动数据"统一管理起来，AI 过滤、通知、去重这些能力立刻产生价值
- 业务人员马上能用起来，不用等爬虫开发

### Phase 2：自动爬取试点（2-3 周）

**目标**：验证"登录 → 爬取 → 过滤 → 通知"完整链路。

| 任务 | 说明 |
|------|------|
| **2.1 开发 LoginCrawler 基类** | 继承 `BaseCrawler`，增加 `login()`、`is_session_valid()`、`auto_relogin()` 方法 |
| **2.2 账号密码安全配置** | `.env` 和 `user_config.json` 支持加密存储平台账号；敏感字段打码显示 |
| **2.3 选 2-3 个平台试点** | 从飞书表格里挑<strong>最简单的</strong>：只有账号密码、无验证码、页面是传统 HTML 或简单 JS |
| **2.4 开发试点爬虫** | 每个平台写一个 `LoginCrawler` 子类，验证登录后解析招标列表 |
| **2.5 健康检测升级** | 支持检测登录状态（Session 是否过期） |

**试点平台挑选标准**（等业务人员反馈后确定）：
1. ✅ 只有账号密码，无图形验证码 / 短信验证码
2. ✅ 登录后招标列表页是 HTML（不是复杂单页应用）
3. ✅ 有有效账号且已购买会员 / 权限正常
4. ✅ 招标信息更新频率高、对业务价值大

## 四、关键技术方案

### 4.1 LoginCrawler 基类设计

```python
class LoginCrawler(BaseCrawler):
    def __init__(self, config, name, url, credentials=None):
        super().__init__(config, name, url)
        self.credentials = credentials  # {username, password}
        self.logged_in = False

    def login(self) -> bool:
        """子类必须实现：执行登录，返回是否成功"""
        raise NotImplementedError

    def is_session_valid(self) -> bool:
        """检测当前 Session 是否还有效"""
        pass

    def crawl(self, stop_event=None):
        if not self.logged_in:
            if not self.login():
                return None  # 登录失败，标记网站不可用
        return super().crawl(stop_event)
```

### 4.2 账号密码安全存储

- 存储位置：`user_config.json`（已存在，且被 Git 忽略）
- 加密方式：用系统生成的密钥对敏感字段做简单对称加密（如 Fernet）
- GUI 显示：密码框显示 `******`，编辑时传空不覆盖原值（已有这个逻辑）

### 4.3 手动导入数据格式

Excel/CSV 模板：

| 标题 | 链接 | 发布日期 | 平台来源 | 内容摘要 | 采购方 |
|------|------|---------|---------|---------|--------|

导入后走同样的流程：关键词匹配 → AI 过滤 → 去重 → 通知

## 五、风险评估与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| 登录平台反爬升级 | 已开发的爬虫失效 | 健康检测发现异常，自动降级为手动导入 |
| CA 证书 / USBKey 平台无法自动化 | 这类平台约占 10-15% | 明确不支持，提供手动导入兜底 |
| 平台页面改版 | 解析逻辑失效 | 每个爬虫加版本检测，失效时告警 |
| 开发周期长，业务等不及 | 系统迟迟无法使用 | Phase 1 先做手动导入，立刻可用 |
